# CliniStudio

Sistema de gestão para salões de beleza, clínicas de estética, barbearias e
espaços de beleza compartilhados.

Agenda, clientes, serviços, caixa, comissões e aluguel de espaços por turno —
com agendamento online para as clientes.

**[clinistudio.app](https://clinistudio.app)**
